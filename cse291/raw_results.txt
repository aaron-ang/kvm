Raw results for redis_bench.md
==============================

Build caveats:
- Redis runs: single run per policy, redis-benchmark inside L2 against localhost,
  EPT on, from build 1b9d1922 (every mark_kvm_page_accessed() commented out).
  Not a valid CLOCK measurement; kept as a record.
- Reuse runs: lru_reuse_test.c under QEMU TCG (kvm_amd.npt=0 kvm.tdp_mmu=0).
  Counters only, no timings. Tables are markdown so they diff and paste cleanly.
